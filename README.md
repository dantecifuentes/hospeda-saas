# Hospeda SaaS

Panel de gestión de cabañas para reservas, cobros, operación y rendimiento comercial.

## Ejecutar
```bash
npm install
npm run dev
```

## Estado actual
Dashboard navegable con datos demo de 10 cabañas. `docs/ARCHITECTURE.md` define la arquitectura de producción y `db/schema.sql` contiene el primer modelo PostgreSQL.
